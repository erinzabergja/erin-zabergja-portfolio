# Erin Zabërgja - Portfolio

A personal one-page portfolio website, made for the Introduction to Web Technologies course at Universum International College in Prishtina, Kosovo.

## About this project

The page is written for a person who selects candidates for a student internship. It shows who I am, my skills, my projects, my education and how to contact me.

## Built with

- HTML
- CSS

## How to open it

Download the project, then open the file `index.html` in a web browser.
