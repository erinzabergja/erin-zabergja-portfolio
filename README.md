# Erin Zabërgja - Portfolio

A personal five-page portfolio website, made for the Introduction to Web Technologies course at Universum International College in Prishtina, Kosovo.

## About this project

The site is written for a person who selects candidates for a student internship. It shows who I am, my skills, my projects, my education and how to contact me.

## Pages

- `index.html` - the home page with my name and logo, a short tagline, the About text and my interests
- `skills.html` - my skills, each with a real example, and the languages I speak
- `projects.html` - my projects: the Dentris website and a sample dental funnel
- `education.html` - my education in a table, and my certificates
- `contact.html` - my email, LinkedIn, GitHub and CV

## Built with

- HTML
- CSS

## How to open it

Download the project, then open the file `index.html` in a web browser. The other pages are linked from the navigation at the top.
